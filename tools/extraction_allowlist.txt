# Differences between the pre-refactor monolith and the extracted package
# that are deliberate. Anything not listed here fails check_extraction.py.
#
# The monolith is a re-export facade on disk now, so compare against the
# last commit where it still held the implementation:
#
#   python tools/check_extraction.py --monolith-rev bc074ad
#
# Format:  function_name: why the difference is correct

atomic_file_write: `import shutil` hoisted from inside the function to module scope; same call, no behavioural change.

main: calls setup_logging() and uses the shared "proxmox-redfish" logger instead of shadowing it with logging.getLogger(__name__). In the monolith that shadow meant main() logged under "__main__" while every other function logged under "proxmox-redfish".

RedfishRequestHandler: debug logging now passes headers, request bodies and response bodies through utils.redaction, so Basic auth credentials, session passwords and freshly issued session tokens no longer reach the journal at REDFISH_LOG_LEVEL=DEBUG. Response contracts are unchanged; verified identical against the live daemon. See tests/unit/test_log_redaction_wiring.py.
